# 问题三：基于分时电价的充电负荷调度与峰谷差优化

---

## 5.1 问题分析

### 5.1.1 问题描述与建模思路

问题三要求采用"峰、平、谷"三段式分时电价，引导用户将充电需求从高峰时段转移至低谷时段，以降低电网峰谷差。具体任务：

- 基于附件3的充电负荷数据，计算调度前各区域及全市的电网峰谷差
- 假设实施分时电价后，高峰时段 20% 的充电负荷可转移至低谷时段
- 给出调度后各区域未来 24 小时负荷曲线
- 计算调度后的峰谷差，评估调度效果

**与前序问题的关系**：问题三独立于问题一和问题二，直接使用附件3的原始充电负荷数据，不需要预测结果也不需要优化配置方案。

**输入数据**：

```
附件3：10区域×24小时×工作日/周末的充电负荷(kWh)
附件4：10区域×24小时电网最大允许负荷(kW)，用于过载风险判定与容量约束叠加
附件5：分时电价参数（峰/平/谷时段划分、电价、2100kW过载判据）
```

### 5.1.2 分时电价参数

根据附件5，三段式分时电价设置如下：

| 时段类型 | 时间段 | 时长(h) | 电价(元/kWh) | 
|:---|:---|:---:|:---:|
| **高峰** | 11:00–14:00, 16:00–23:00 | 10 | 1.19 |
| **平段** | 07:00–11:00, 14:00–16:00 | 6 | 0.70 |
| **低谷** | 00:00–07:00 | 8 | 0.21 |

> 高峰电价上浮70%、低谷电价下浮70%，峰谷电价差达5.7倍，价格信号强烈。

### 5.1.3 关键假设

1. **负荷转移方向**：仅发生高峰→低谷单向转移，平段负荷保持不变
2. **转移比例**：高峰时段各小时 20% 的充电负荷可被转移
3. **填谷优先分配**：转移负荷优先填入低谷中负荷最低的时段，使低谷曲线尽可能拉平（同时保留均匀分配作为基准对比方案）
4. **用户响应一致性**：各区域用户对分时电价的响应比例相同（20%）
5. **总用电量不变**：负荷转移前后全市总充电量保持不变

## 5.2 峰谷差计算与负荷转移模型

### 5.2.1 符号定义

| 符号 | 含义 | 单位 |
|:---|:---|:---:|
| \(L_{i,d}(t)\) | 区域i在日期类型d、时段t的原始充电负荷 | kW |
| \(T_{peak}, T_{flat}, T_{valley}\) | 高峰、平段、低谷时段集合 | — |
| \(\eta = 0.20\) | 负荷转移率（高峰→低谷） | — |
| \(L'_{i,d}(t)\) | 转移后区域i时段t的充电负荷 | kW |
| \(\Delta P_{i,d}\) | 区域i的峰谷差 | kW |
| \(R_{i,d}\) | 区域i的峰谷比 | — |

其中 \(i = 1, 2, ..., 10\)，\(d \in \{weekday, weekend\}\)，\(t = 0, 1, ..., 23\)。

### 5.2.2 调度前峰谷差计算

**各区域峰谷差**：

$$\Delta P_{i,d}^{before} = \max_{t} L_{i,d}(t) - \min_{t} L_{i,d}(t)$$

**全市汇总峰谷差**：

$$\Delta P_{total,d}^{before} = \max_{t} \sum_{i=1}^{10} L_{i,d}(t) - \min_{t} \sum_{i=1}^{10} L_{i,d}(t)$$

**峰谷比**：

$$R_{i,d} = \frac{\max_t L_{i,d}(t)}{\min_t L_{i,d}(t) + \epsilon}$$

其中 \(\epsilon = 1\) kW，防止谷值接近零时峰谷比失稳。考虑到周末凌晨部分区域谷值低至 21 kW，峰谷比在该场景下缺乏物理意义——本文以**峰谷差**和**负荷率**为主要评价指标，峰谷比仅作参考。

**负荷率**（补充评价指标）：

$$\text{LoadRate}_{i,d} = \frac{\bar{L}_{i,d}}{\max_t L_{i,d}(t)} \times 100\%$$

负荷率反映负荷曲线的平坦程度，越接近100%越均衡。

### 5.2.3 负荷转移模型

#### 转移量计算

对每个区域 \(i\)、每个日期类型 \(d\)：

**高峰时段可转移负荷量**：

$$L_{i,d}^{transfer}(t) = \eta \cdot L_{i,d}(t), \quad t \in T_{peak}$$

**高峰时段转移总量**：

$$Q_{i,d}^{transfer} = \sum_{t \in T_{peak}} L_{i,d}^{transfer}(t) = \eta \cdot \sum_{t \in T_{peak}} L_{i,d}(t)$$

#### 负荷重新分配

本文采用两种分配策略并对比：

**方案A — 均匀分配（基准方案）**：转移总量均匀加至 8 个低谷小时。

$$L'_{i,d}(t) = L_{i,d}(t) + \frac{Q_{i,d}^{transfer}}{|T_{valley}|}, \quad t \in T_{valley}$$

**方案B — 填谷优先（优化方案）**：采用 water-filling 算法，将低谷 8 小时按负荷从低到高排序，转移量优先填入负荷最低的时段，逐层填平直至用尽。目标是使低谷段负荷曲线尽可能平坦，避免均匀分配可能造成的"新尖峰"现象。

设低谷时段集合排序后为 \(t_1 < t_2 < ... < t_8\)（按 \(L(t)\) 升序），填谷算法：

\[
\begin{aligned}
&\text{for } k = 1, 2, ..., 7: \\
&\quad gap = L(t_{k+1}) - L(t_k) \\
&\quad \text{if } Q \geq gap \times k: \\
&\quad\quad \text{将 } t_1 \sim t_k \text{ 的负荷填高至 } L(t_{k+1}),\quad Q \leftarrow Q - gap \times k \\
&\quad \text{else}: \\
&\quad\quad \text{将 } t_1 \sim t_k \text{ 的负荷均分剩余 } Q \text{ → 结束}
\end{aligned}
\]

**转移后高峰时段负荷**：

$$L'_{i,d}(t) = L_{i,d}(t) - L_{i,d}^{transfer}(t) = (1 - \eta) \cdot L_{i,d}(t), \quad t \in T_{peak}$$

**平段负荷不变**：

$$L'_{i,d}(t) = L_{i,d}(t), \quad t \in T_{flat}$$

### 5.2.4 调度后峰谷差计算

$$\Delta P_{i,d}^{after} = \max_{t} L'_{i,d}(t) - \min_{t} L'_{i,d}(t)$$

## 5.3 调度效果评估

### 5.3.1 核心评估指标

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| **峰谷差降低率** | \(\gamma_i = \frac{\Delta P_i^{before} - \Delta P_i^{after}}{\Delta P_i^{before}} \times 100\%\) | 峰谷差改善相对幅度 |
| **峰谷差绝对降幅** | \(\Delta P_i^{before} - \Delta P_i^{after}\) (kW) | 绝对改善量 |
| **负荷率提升** | \(\text{LoadRate}_i^{after} - \text{LoadRate}_i^{before}\) (百分点) | 负荷曲线平坦化程度 |
| **高峰负荷削峰率** | \(\frac{\max_t L_i(t) - \max_t L'_i(t)}{\max_t L_i(t)} \times 100\%\) | 峰值削减效果 |

### 5.3.2 电网过载风险再评估

采用双层判据评估过载风险：**第一层（附件4）**——各区域各时段充电负荷不得超过该区域该时段的电网最大允许负荷；**第二层（附件5）**——若负荷 > 2100 kW 且持续 > 15 min，判定为过载事件。两层约束同时检验：

- 统计调度前/后违反附件4容量上限的区域和时段数量
- 统计调度前/后触发附件5 2100kW判据的区域和时段数量
- 识别调度无法完全消除过载风险的薄弱区域（两种判据任一种仍超标）

## 5.5 模型特色总结

| 要点 | 说明 |
|:---|:---|
| **双层负荷分配策略** | 均匀分配为基准、填谷优先为优化，对比评估两种策略的填谷效果 |
| **双层电网约束分析** | 附件4（区域容量上限）+ 附件5（2100kW过载判据）叠加检验，明确两套标准的适用层级 |
| **多维度评估体系** | 以峰谷差和负荷率为核心指标，峰谷比仅作参考（谷值接近零时失稳） |
| **区域异质性分析** | 区分10个区域的差异化响应效果，识别电价政策的重点调控区域 |
| **工作日/周末分别建模** | 两类日期充电模式差异大，分别计算更贴近实际 |
